## Selected work

### [ChronoTrade](https://github.com/GTU-Blockchain/chronotrade-ethglobal-prague)
Trade skills and services for time: one TIME token represents one hour of work. Built with an ERC-20 token, smart-contract escrow and a reputation system.

**Blockscout Big Explorer Pool Prize · ETHGlobal Prague 2025**<br>
<sub>Solidity · Hardhat · React · Wagmi · Ethers.js</sub>

### [BitBrawlers](https://github.com/GTU-Blockchain/bitbrawlers-ethrome-2025)
Mint, level up and battle NFT cats on-chain. Each cat gets its own ENS subdomain.

**ENS track prize · ETHRome 2025**<br>
<sub>Solidity · ENS · Scaffold-ETH 2</sub>

### [PPE detection](https://github.com/melik-droid/ceng-mod01-ppe-detection)
The vision module of an autonomous safety inspection robot. Detects missing protective equipment on a Raspberry Pi 5 and publishes violation events over MQTT.

<sub>Python · YOLOv8 · ONNX Runtime · OpenCV · MQTT</sub>

### [Obscura](https://github.com/GTU-Blockchain/obscura-monad-blitz-istanbul)
Anonymous voting and sealed-bid auctions on Monad, using commit-reveal cryptography. Built at Monad Blitz Istanbul 2025.

<sub>Solidity · Hardhat · React · Wagmi · Ethers.js</sub>
